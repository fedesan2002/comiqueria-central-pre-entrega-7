# Comiquería Central 7

Proyecto realizado para la pre-entrega de JavaScript sobre interfaz dinámica,
manipulación del DOM y eventos.

El catálogo se genera dinámicamente desde un array de objetos de la clase
`Producto`. Cada tarjeta se dibuja con `innerHTML` y template strings.

## Interacciones

- Buscar títulos en vivo mediante un evento de teclado.
- Filtrar por categoría.
- Agregar un nuevo manga o cómic desde un formulario, sin recargar la página.
- Agregar, quitar o vaciar productos del carrito.
- Eliminar títulos del catálogo.
- Recibir feedback visual dentro de la página para cada acción.
